# KUDCLIP

**РОЛИКИ ДОЛЖНЫ АВТОМАТИЧЕСКИ НАХОДИТЬСЯ, НАРЕЗАТЬСЯ, ПУБЛИКОВАТЬСЯ И НАБИРАТЬ ПРОСМОТРЫ.**

Локальная нарезка YouTube и Twitch в вертикальные клипы. Для запуска открой
`ЗАПУСК_WINDOWS.bat` и оставь приложение включённым на время работы автопилота.

## Ежедневный выпуск

- У YouTube и Twitch проверяется точный возраст публикации до 48 часов. Автопилот
  сравнивает два замера просмотров, скорость роста и показатели других роликов
  канала. Свежие находки из общего поиска YouTube видны как рекомендации каналов.
- Автопилот проверяет, что в первые три секунды появляется конкретный повод
  смотреть дальше, основная речь на русском, сцена понятна отдельно от исходника,
  а развязка подтверждается речью или кадрами. Дневная цель — от 1 до 3 сильных
  клипов при лимите до 3 исходников.
- Субтитры используют Montserrat Black Italic. В профиле можно выбрать рекламное
  изображение PNG, JPG или WebP. Оно появится в следующих сборках. По желанию
  можно загрузить собственную вставку для нижней части кадра. Она беззвучна
  и применяется к разговорным сценам. Короткий звук начала выключен по умолчанию.
- В разделе «Автопост» открой окно входа для каждой площадки, войди, привяжи
  аккаунт и включи публикацию. Playwright работает с интерфейсом площадки в Edge
  или подключённом Octo. Для рекламных клипов укажи тип рекламы в профиле.
  Если площадка не позволяет подтвердить отметку, открой готовый MP4 для ручного
  выпуска. Для опубликованных роликов с доступными счётчиками сохраняются замеры
  просмотров через 24 и 48 часов.

Отбор анализирует весь исходник, ищет законченные эпизоды, проверяет источник и
развязку отдельным проходом и удаляет повторы. Количество клипов — максимум:
если достойных моментов нет, результат может быть пустым. Длина определяется
смыслом в пределах настроек профиля.

Работают только явно подтверждённые ключи **бесплатных аккаунтов Groq**.
Приложение не определяет тариф по ключу: отметку можно ставить только для Free
аккаунта с выключенной платной оплатой. Gemini и платный запасной Whisper не
подключены. При нехватке бесплатной квоты задача ждёт и продолжает сохранённые
этапы. Учёт квот оставляет 20% запаса. Ключи одной организации следует объединять
одной группой квоты; для отдельных аккаунтов поле группы оставляют пустым.

Проверка кадров использует Groq Vision и сетки изображений по всему материалу плюс
подробные кадры кандидатов. Это разреженный просмотр, он может пропустить очень
быстрое игровое событие. Звуковые пики — только подсказки для поиска, а не оценка
интересности.

В галерее доступны правка границ, текста субтитров, подписи и горизонтального
центра кадрирования, оценки удачных и неудачных клипов. Правка создаёт новую
версию, исходный клип сохраняется. Изменение количества слов в субтитрах
распределяет текст по имеющемуся речевому интервалу; проверьте синхронизацию.

Очередь обрабатывает одну задачу за раз, поддерживает отмену, повтор и
восстановление после перезапуска. Передача Telegram хранит результат отдельно
для каждого получателя. При неизвестном результате после обрыва связи проверьте
чат перед явным повтором, чтобы не получить дубль.

Данные находятся в `backend/data`, медиа — в `backend/media`. JSON сохраняются
атомарно с предыдущей версией `.bak`; повреждённые данные не перезаписываются.
Транскрипты и результаты анализа используются повторно между профилями.

Исходники до 30 минут анализируются целиком. Из длинных выпусков автопилот берёт
до трёх окон по 180 секунд, если YouTube вернул достоверные главы или отметки.
Доступное число задач зависит от бесплатных квот аккаунтов.

Проверки без API и Telegram (из каталога проекта):

```text
python -m unittest discover -s backend/offline_tests -v
cd frontend
npm run build
```

Старые сетевые тесты `backend/tests` отключены по умолчанию: они рассчитаны на
отдельный тестовый сервер и могут менять токены. Не запускайте их на рабочей базе.
